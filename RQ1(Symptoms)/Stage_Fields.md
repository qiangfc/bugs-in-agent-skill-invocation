# Stage Fields in RQ1

Figure 3 cross-tabulates symptom codes and `Invocation stage` for the 901 retained reports. The full-sample workbook carries this field forward from the original summary table.

The RQ1 coding records store the stage at which the failure was observed as `Observed stage`. In the pilot consolidation workbook, the field is named `Observed failure stage`. Use the Issue URL to join these records to the full-sample workbook. The pilot consolidation workbook identifies cases where the observed stage was filled from the full-sample invocation stage.

# Stage Fields in RQ2

The result that 21 of 24 root-cause categories have reports in all four stages uses `Invocation stage` from the full-sample workbook. This field comes from the original summary table. The result describes the distribution of reports by recorded invocation stage for each root-cause category.

The RQ2 coding records store the stage where the root-cause mechanism resides as `Root-cause stage`. Use the Issue URL to join these records to the full-sample workbook. The pilot consolidation workbook identifies cases where the root-cause stage was filled from the full-sample invocation stage.
